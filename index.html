BookmarkCove — free, private bookmark manager that runs in your browser

A bookmark manager that runs entirely on your device

BookmarkCove is a single-file tool. Import the bookmarks.html export from any browser, clean out what you no longer need, move links between folders, and export a file that imports straight back into Chrome, Firefox, Edge, Safari, Opera or Brave. No account. No server. No analytics.

Private by design

Your bookmarks never leave the browser. Everything is stored in local storage on this device — there is no backend to send them to.

Folder-aware export

Exports use the standard Netscape bookmark format, so nested folders survive the round trip back into your browser.

Fast cleanup

Bulk-select to delete or move many bookmarks at once, drag links between folders, tag them, and detect duplicate URLs in one click.

Frequently asked questions

Which import formats are supported?

Netscape bookmarks.html (all browsers), plus JSON, JSONL, and CSV. If you have a plain list of bookmarks in a spreadsheet, save it as CSV with columns for name and URL.

Can a website read my browser bookmarks directly?

No. Browsers deliberately keep the bookmarks database private, so no web page can read it. You either import an exported file, or drag a single bookmark from your bookmarks bar onto this page.

Where exactly is my data stored?

In this browser's local storage, under the key bc-tree-v1. It stays on this device and is visible only to BookmarkCove on this domain.

Do the site icons get sent anywhere?

Icons embedded in your bookmark file are used offline first. For links without one, BookmarkCove can request a favicon from DuckDuckGo's icon service — that reveals the domain name to that service, nothing else. Turn it off in Settings to disable.

How do I get the cleaned-up bookmarks back into my browser?

Click Export. The downloaded bookmarks.html can be imported by any major browser and keeps your folder structure and tags intact.
