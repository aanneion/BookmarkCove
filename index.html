BookmarkCove — free, private bookmark manager that runs in your browser

A bookmark manager that runs entirely on your device

BookmarkCove is a single-file tool. Import the bookmarks.html export from any browser, clean out what you no longer need, move links between folders, and export a file that imports straight back into Chrome, Firefox, Edge, Safari, Opera or Brave. No account. No server. No analytics.

Private by design

Your bookmarks never leave the browser. Everything is stored in local storage on this device — there is no backend to send them to.

Folder-aware export

Exports use the standard Netscape bookmark format, so nested folders survive the round trip back into your browser.

Fast cleanup

Delete a single link or a whole folder, restore anything by mistake, and move bookmarks between categories in one click.

Frequently asked questions

Can I import bookmarks from Chrome, Firefox or Edge?

Yes. In Chrome open Bookmark manager → ⋮ → Export bookmarks. In Firefox use Manage bookmarks → Import and Backup → Export bookmarks to HTML. Both produce a bookmarks.html file you can drop into BookmarkCove.

Can a website read my browser bookmarks directly?

No. Browsers deliberately keep the bookmarks database private, so no web page can read it. You either import an exported file, or drag a single bookmark from your bookmarks bar onto this page. Full two-way access would require installing a browser extension.

Where exactly is my data stored?

In this browser's local storage, under the key bc-tree-v1. It stays on this device and is visible only to BookmarkCove on this domain. Clearing site data removes it permanently, so export a backup before you do that.

Do the site icons get sent anywhere?

Icons embedded in your bookmark file are used offline first. For links without one, BookmarkCove can request a favicon from DuckDuckGo's icon service — that reveals the domain name to that service, nothing else. You can turn this off in Settings at any time; each bookmark then shows a generated letter badge instead.

How do I get the cleaned-up bookmarks back into my browser?

Click Export. The downloaded bookmarks.html can be imported by any major browser and keeps your folder structure intact.
